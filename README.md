# dealer-system

Sitio web estático para un concesionario de vehículos (AutoMax).

## Contenido

- `index.html` — página principal (inicio, inventario, servicios, nosotros, contacto)
- `assets/css/styles.css` — estilos
- `assets/js/main.js` — filtro de inventario, menú móvil y formulario de contacto

## Uso

Abre `index.html` en el navegador, o sirve el directorio con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
